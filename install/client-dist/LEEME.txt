Fitness Training Management Platform
=====================================

INSTALACION

  Descomprimir de GitHub en C:\FitnessTraining\
  Ejecutar:  Iniciar.bat

  Iniciar.bat instala automaticamente (winget) si faltan:
    - Java 21
    - Maven (primera compilacion desde GitHub)
    - Docker Desktop (PostgreSQL en contenedor)

  Luego compila, configura, levanta la base y abre la app.

USO DIARIO:  Iniciar.bat
